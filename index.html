Full-Stack Reactive Apps Without Browser Runtimes.

Eronom is an ultra-fast full-stack web framework built for fine-grained reactive UIs. Zero Virtual-DOM overhead, native Rust HMR engine, and instant compilation.

Get Started → View Speed Benchmarks
$ eronom create my-app
⚡

Fine-Grained Signals

No virtual DOM diffing. Eronom signals update the exact DOM nodes automatically when state values change.

🔥

Sub-Millisecond HMR

Native Rust IPC IPC server updates components in real-time under 0.2ms without losing active browser state.

🌐

Zero-Config API Routes

Full-stack out of the box. Define server HTTP routes in server/api/routes.er with type safety.

🎨

Scoped Component CSS

Clean <style> blocks inside .erm components isolated to component boundaries.

  let double = useState(() => count * 2);
